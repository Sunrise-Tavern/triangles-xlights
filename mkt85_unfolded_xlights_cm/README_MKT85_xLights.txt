MKT-85 UNFOLDED REFERENCE MODEL FOR xLIGHTS
============================================

Files
-----
mkt85_unfolded_cm.obj
mkt85_unfolded_materials.mtl

Scale and axes
--------------
Units are centimeters.
X = trailer length, positive toward the drawbar.
Y = trailer width.
Z = height.
Origin = center of the published operational envelope at ground level.

Published operational envelope represented
-------------------------------------------
Length: 510.54 cm  (201 in)
Width:  386.08 cm  (152 in)
Height: 335.28 cm  (132 in)

Model contents
--------------
- Main trailer deck and unfolded side/end platforms
- Single axle, wheels, chassis, drawbar, and stabilizer legs
- Raised roof posts and deployed green canvas canopy
- Simplified cooking/storage equipment banks
- Handrails and three compact stair approximations

Important limitations
---------------------
This is a deliberately simplified visual reference for xLights Layout.
Exact cabinet placement, canvas drape, stair geometry, frame-member sizes,
and chassis details are approximate. Do not use it for fabrication,
loading, clearance certification, or structural design.

xLights import
--------------
Keep the OBJ and MTL files in the same folder. Import the OBJ as a static
mesh/object. Preserve equal X, Y, and Z scale values. If xLights treats
OBJ units differently, apply one uniform scale factor.
