Modeling assumptions
--------------------
The 10-foot base width supplied by the user is exact. Overall height,
post spacing, sign curvature, doorway width, panel thickness, and flame
placement were estimated from the supplied frontal photograph using the
two adults as scale checks.

The sign lettering is raised vector geometry rather than a texture, so it
should remain visible in an OBJ/MTL-only xLights workflow. The flame
graphics are simplified raised shapes, not a precise tracing of the artwork.

xLights import
--------------
Keep the OBJ files and MTL file together. Import any OBJ as a static mesh.
Use equal X, Y, and Z scale values. The combined model is ready to place,
while the component files allow the arch and doors to be adjusted
independently.
