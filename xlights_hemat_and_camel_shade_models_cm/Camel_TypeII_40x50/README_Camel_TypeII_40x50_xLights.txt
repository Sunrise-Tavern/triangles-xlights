Geometry represented
--------------------
- Single 40 x 50 Type II arrangement
- 3 x 3 telescoping-pole grid
- Four joined high-roof fabric panels
- Sloped desert-tan perimeter shade wings
- Center seams, corner anchor seams, and corner stakes

Source discrepancy
------------------
Some military summaries list the Type II as 50 x 50 while also listing
2,000 square feet of coverage. Supplier documentation lists 40 x 50,
which is internally consistent with 2,000 square feet and is the
configuration modeled here at the user's request.

Limitations
-----------
This is a simplified xLights reference mesh. Exact fabric catenary,
pole locations, seam layout, fittings, stakes, and tensioning hardware
are approximated from published specifications and reference imagery.
